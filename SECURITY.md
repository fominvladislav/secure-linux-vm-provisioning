# Security

Репозиторий содержит только публичные учебные примеры.

Запрещено добавлять:

- пароли и токены
- private keys, учетные данные и другие материалы аутентификации
- реальные домены и IP-адреса
- внутренние URL
- имена сотрудников;
- SID и реальные AD-группы;
- production inventory;
- необезличенные скриншоты административных консолей;
- конфигурации с секретами;
- логи, содержащие секреты, внутренние адреса, имена или другие чувствительные данные.

Перед публикацией необходимо проверить не только текущие файлы, но и всю Git-историю.
